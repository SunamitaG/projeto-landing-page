
# Landing Page — Escola DNC

Projeto desenvolvido durante o módulo base do curso de Tecnologia da Escola DNC.

A aplicação consiste em uma landing page informativa para apresentação de um curso introdutório de tecnologia, com seções de conteúdo, vídeo, depoimentos e formulário de inscrição.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Apresentação do curso e suas informações.
- Incorporação de vídeo do YouTube.
- Carrossel interativo de depoimentos.
- Formulário para preenchimento de dados.
- Organização de arquivos HTML, CSS, JavaScript e recursos visuais.

## Estrutura do projeto

```text
projeto-landing-page/
├── cards/

├── imagens/

├── index.js
```
